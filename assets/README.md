# Assets

This folder contains the visual material used to document and present the MPLS Traffic Engineering project.

## Contents

| File | Description |
|---|---|
| `topology.png` | Main GNS3 network topology |
| `tunnel-path-a.png` | MPLS-TE Tunnel0 / PATH_A verification |
| `tunnel-path-b.png` | MPLS-TE Tunnel1 / PATH_B verification |
| `rsvp-reservations.png` | RSVP-TE bandwidth reservation verification |
| `ospf-neighbors.png` | OSPF neighbor verification |
| `connectivity-test.png` | PC1 to PC2 connectivity test |
| `hero.gif` | Project showcase animation |
| `logo.png` | Repository/project logo |
| `project-preview.png` | Project preview image |

## Purpose

The screenshots provide visual evidence of the actual GNS3 implementation and Cisco IOS verification results.

They are referenced from the main repository README to make the project easier to understand without opening the configuration files.
